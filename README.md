VoicePad — бесплатный Soundpad с изменением голоса
===================================================

ЧТО ЭТО
-------
Программа для изменения голоса в реальном времени и воспроизведения
звуков в микрофон. Работает с Discord, Skype, Zoom, OBS, играми.

БЫСТРЫЙ СТАРТ
-------------
1. Запустите VoicePad
2. Выберите:
   - Вход (микрофон) — ваш физический микрофон
   - Выход — "CABLE Input (VB-Audio Virtual Cable)"
3. Нажмите "Запустить обработку"
4. В Discord: Настройки → Голос и видео → Устройство ввода = "CABLE Output"

ЕСЛИ НЕТ VB-CABLE
-----------------
Скачайте вручную: https://vb-audio.com/Cable/
Установите от имени администратора, перезагрузитесь.

МОНИТОРИНГ (СЛЫШАТЬ СЕБЯ)
-------------------------
Win+R → mmsys.cpl → вкладка "Запись" → CABLE Output → Свойства →
вкладка "Прослушивать" → галочка + выбрать наушники.

ГОРЯЧИЕ КЛАВИШИ
---------------
Пока не поддерживаются. См. будущие версии.

НАСТРОЙКИ
---------
Хранятся в %APPDATA%\VoicePad\config.json
Звуки — в %APPDATA%\VoicePad\sounds\

УДАЛЕНИЕ
--------
Панель управления → Программы и компоненты → VoicePad → Удалить
